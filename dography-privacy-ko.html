Dography 개인정보 처리방침

Dography는 사용자가 직접 촬영하거나 선택한 강아지 사진으로 성장앨범과 포토카드를 만드는 iPhone 앱입니다.

시행일: 2026년 7월 25일 · 최종 개정일: 2026년 7월 26일

Dography 운영자는 현재 출시 버전에서 사용자의 사진, 강아지 프로필 또는 앱 사용 기록을 서버로 수집하지 않습니다.

1. 기기 안에서 처리되는 정보

다음 정보는 계정과 연결되지 않으며, 사용자의 iPhone에 있는 앱 전용 저장 공간에서만 처리됩니다.

  • 강아지 프로필: 사용자가 입력한 이름, 생년월일, 품종, 체중 등의 정보
  • 성장앨범: 사용자가 직접 촬영하거나 사진 보관함에서 선택한 사진, 날짜와 대표 사진 등의 구성 정보
  • 포토카드: 포토카드 편집값과 저장 정보
  • 기술 이벤트: 사용성 개선을 위해 기록되는 경우에도 기기 내부에만 저장되는 앱 사용 정보

이 정보는 Dography 서버로 전송되지 않습니다.

2. 카메라와 사진

  • 카메라: 사용자가 촬영을 선택한 경우에만 강아지 사진을 찍기 위해 사용합니다.
  • 사진 보관함: 사용자가 직접 선택한 사진만 앱으로 가져옵니다.
  • 기기 내 품질 확인: 강아지 포함 여부와 선명도 등의 기술적 확인은 기기 안에서 수행되며, 사진과 확인 결과는 외부 서버로 전송되지 않습니다.
  • 임시 파일: 처리 중 만들어진 임시 파일과 추가되지 않은 사진은 처리 후 삭제합니다. 앱이 예기치 않게 종료되어 남은 임시 파일은 다음 실행 때 정리합니다.

3. 사진 저장·내보내기와 공유

사진 앱 저장, 포토카드 내보내기, ZIP 백업 또는 iOS 공유 화면 열기는 사용자가 직접 선택한 경우에만 실행됩니다.

사진 앱, 파일 앱 또는 사용자가 선택한 다른 앱으로 내보낸 사본은 Dography의 앱 전용 저장 공간 밖에 남을 수 있습니다. 이후 보관과 삭제에는 해당 앱 또는 서비스의 정책이 적용됩니다.

4. 결제 정보

Pro 결제와 구매 복원은 Apple의 App Store가 처리합니다. Dography는 카드 번호, 결제 계좌 또는 Apple ID를 직접 수집하지 않습니다. 앱에는 구매 확인 결과와 Pro 활성 상태만 보관됩니다.

Apple이 처리하는 결제 정보에는 Apple 개인정보 처리방침이 적용됩니다.

5. 수집·분석·추적 및 제3자 제공

현재 버전은 사용자 계정, 위치 정보, 광고 식별자 또는 연락처를 수집하지 않으며, 광고·제3자 분석 SDK와 사용자 추적 기능을 사용하지 않습니다.

Dography 운영자는 사진, 프로필, 포토카드 또는 사용 기록을 제3자에게 판매하거나 제공하지 않습니다. 다만 사용자가 iOS 공유 화면에서 다른 앱이나 서비스를 선택하면 사용자가 선택한 대상의 정책에 따라 정보가 처리될 수 있습니다.

6. 보관 기간과 삭제

  • 앱 안의 사진과 프로필은 사용자가 삭제할 때까지 기기 내부에 보관됩니다.
  • 사용자는 앱에서 사진과 프로필을 직접 삭제할 수 있습니다.
  • 앱을 삭제하면 앱 전용 저장 공간의 데이터도 함께 제거됩니다.
  • 사진 앱, 파일 앱, ZIP 백업 또는 다른 앱으로 내보낸 사본은 앱 삭제로 제거되지 않으므로 사용자가 해당 위치에서 직접 삭제해야 합니다.
  • 현재 버전은 자동 iCloud 동기화를 사용하지 않습니다.
앱 삭제나 기기 교체 전에는 필요한 성장앨범을 ZIP으로 내보내고, 중요한 사진은 사진 앱에도 별도로 보관해 주세요.

7. 권한 관리와 동의 철회

카메라와 사진 접근 권한은 iOS 설정의 Dography 항목에서 언제든지 변경하거나 철회할 수 있습니다. 권한을 철회하면 해당 기능은 제한될 수 있지만, 이미 앱에 저장된 사진과 프로필은 사용자가 삭제하기 전까지 유지됩니다.
