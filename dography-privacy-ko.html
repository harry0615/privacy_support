Dography 개인정보 처리방침

Dography는 사진 보관함에서 우리 강아지의 최근 사진을 찾아, 한 주의 순간을 사진과 세로 영상으로 만드는 iPhone 앱입니다. 사진 검색과 이야기 만들기는 사용자가 시작할 때 실행됩니다.

시행일: 2026년 11월 3일 · 최초 시행일: 2026년 7월 25일 · Dography 1.7

사진, 강아지 프로필, 식별 특징값과 녹음한 목소리는 기기 안에서 처리합니다. 앱 개선을 위한 익명 사용 통계 전송과 끄는 방법은 아래 5항에 별도로 설명합니다.

1. 기기 안에서 처리되는 정보

강아지 프로필, 사용자가 촬영·선택한 사진, 최근 사진에서 계산한 강아지 포함 여부·식별 유사도·선명도·밝기·구도 점수, 성장앨범과 포토카드·주간 이야기 구성 정보는 앱 전용 저장 공간에서 처리됩니다. 이 정보는 계정과 연결되지 않으며 Dography 서버로 전송되지 않습니다.

2. 카메라와 사진

카메라는 사용자가 촬영을 선택한 경우에만 사용합니다. 주간 이야기 자동 검색은 사용자가 기능을 시작한 뒤 iOS에서 허용한 범위의 최근 사진을 기기 안에서 살펴봅니다. Vision을 이용한 강아지 감지·기준 사진과의 유사도 비교·품질 평가는 기기 안에서 수행됩니다. 후보 임시 사본은 처리 후 정리되며, 최종 확정한 이야기의 사진 사본과 완성본만 앱 전용 공간에 보존됩니다.

마이크는 사용자가 카메라 화면에서 '내 목소리'를 녹음할 때만 사용합니다. 녹음 파일은 강아지의 시선을 끌기 위한 재생 용도로 앱 전용 공간에만 저장되며, 다시 녹음하면 이전 파일은 교체됩니다. 알림은 사용자가 켠 경우에만 기기 안에서 예약되며 서버를 거치지 않습니다.

3. 사진 저장·내보내기와 공유

사진 앱 저장, 포토카드 내보내기, ZIP 백업 또는 iOS 공유 화면 열기는 사용자가 직접 선택한 경우에만 실행됩니다. 사진 앱, 파일 앱 또는 사용자가 선택한 다른 앱으로 내보낸 사본은 Dography의 앱 전용 저장 공간 밖에 남을 수 있으며, 이후 보관과 삭제에는 해당 앱 또는 서비스의 정책이 적용됩니다.

전체 백업·복원

사진, 프로필, 기준 사진, 주간 이야기와 카드 편집 정보를 ZIP으로 보관하고 복원해요. 구입 내역은 백업에 포함되지 않아요.

복원하면 현재 사진·프로필·이야기·카드 편집 정보가 선택한 백업 내용으로 교체돼요. 현재 기록을 보관하려면 먼저 전체 백업을 만들어 주세요. 구입 상태는 그대로 유지돼요.

백업 ZIP에는 사진과 프로필 등 개인 기록이 포함되며, 앱에서 별도의 암호를 설정하지 않습니다. 신뢰하는 저장 위치와 공유 대상만 선택해 주세요. 구입 내역과 ‘내 목소리’ 녹음은 백업에 포함되지 않습니다. 보관할 완성 영상은 사진 앱이나 파일 앱에도 별도로 저장해 주세요.

4. 결제 정보

Pro 결제와 구매 복원은 Apple의 App Store가 처리합니다. Dography는 카드 번호, 결제 계좌 또는 Apple ID를 직접 수집하지 않습니다. 앱에는 구매 확인 결과와 Pro 활성 상태만 보관되며, Apple이 처리하는 결제 정보에는 Apple의 개인정보 처리방침이 적용됩니다.

무료 체험의 중복 시작을 막기 위해 체험 시작 시각을 기기의 Keychain에도 보관합니다. 이 기록은 앱을 삭제하고 다시 설치해도 남을 수 있습니다. 결제와 체험 상품의 구입 기록은 Apple이 관리합니다.

5. 광고와 제3자 처리

이 버전의 Dography에는 광고 SDK가 포함되어 있지 않습니다. 사용자 계정·연락처를 수집하지 않으며 강아지 사진, 프로필, 녹음한 목소리, 기기 안의 분석 결과를 제3자에게 제공하지 않습니다.

익명 사용 통계: 앱 개선을 위해 결제 화면 노출, 구매 시도·결과, 구매 복원·체험 시작·종료·Pro 음악 선택 같은 결제 관련 이벤트, 주간 이야기 이용 이벤트(사진 검색·완성·사진 빼기·저장·공유 여부와 검토한 사진 수, 처리 시간, 오류 종류 같은 숫자 정보), 하루 한 번의 앱 사용 여부를 TelemetryDeck GmbH(독일)에 보낼 수 있습니다. 함께 보내는 정보에는 이벤트 시각, 앱 버전, 플랫폼(iOS), 언어·지역 설정, 이용 상태(무료·체험·평생 Pro), 완성한 이야기 수, 설치 후 경과 일수, 기기에서 무작위로 만든 설치 ID의 해시값이 포함되며, 사진·강아지 이름·프로필·광고 식별자는 보내지 않습니다. 이 통계는 사용자를 식별하거나 광고 추적에 사용하지 않습니다. 우리 아이 › 앱 정보에서 '익명 사용 통계 보내기'를 끄면 전송이 중단되고 아직 보내지 않은 기록도 삭제됩니다.

6. 보관 기간과 삭제

프로필, 성장앨범 사진, 기준 사진, 확정한 주간 이야기의 선택 사진 사본과 완성본은 사용자가 삭제할 때까지 기기 내부에 보관됩니다. 따라서 사진 앱의 원본을 삭제해도 확정한 이야기는 유지됩니다. 앱을 삭제하면 앱 전용 저장 공간의 데이터도 제거됩니다. 사진 앱·파일 앱·ZIP 백업·다른 앱으로 내보낸 사본은 해당 위치에서 직접 삭제해야 합니다. 현재 버전은 자동 iCloud 동기화를 사용하지 않습니다.

앱 전용 사진·프로필·이야기를 삭제해도 이미 내보낸 백업 ZIP은 자동으로 삭제되지 않습니다. 해당 저장 위치에서 별도로 삭제해야 합니다. ‘내 목소리’ 파일은 다시 녹음하면 교체되며 앱 삭제 시 앱 전용 저장 공간에서 제거됩니다. 체험 시작 기록은 위 4항의 예외가 적용됩니다.

7. 권한 관리와 동의 철회

카메라와 사진 접근은 iOS 설정의 Dography 항목에서 언제든지 변경하거나 철회할 수 있습니다. 제한된 사진 접근을 선택하면 허용한 사진만 검색합니다. 권한을 철회하면 새 사진 검색은 중단되지만 이미 앱에 보존한 이야기와 프로필은 사용자가 삭제하기 전까지 유지됩니다. 개인정보 문의 또는 삭제 지원 요청은 아래 이메일로 접수할 수 있습니다.

마이크와 알림 권한도 iOS 설정에서 변경하거나 철회할 수 있습니다. 마이크를 허용하지 않아도 사진 검색과 주간 이야기 만들기는 사용할 수 있습니다.
