Dography 개인정보 처리방침

Dography는 강아지와 함께 놀며 좋은 순간을 자동으로 골라 기기 안의 성장앨범에 보관하는 iPhone 앱입니다.

2. 처리하는 정보와 이용 목적

현재 버전은 계정 가입을 요구하지 않으며 Dography 사업자 서버를 운영하지 않습니다. 아래 정보는 앱 기능 제공을 위해 사용자의 iPhone 안에서 처리됩니다.

  • 강아지 프로필: 이름, 생년월일 또는 나이와 사용자가 선택해 입력한 품종, 체중, 성별, 중성화 여부 등. 맞춤 놀이와 성장 기록 표시에 사용합니다.
  • 성장앨범: 앱이 놀이 중 자동으로 고른 사진, 촬영 날짜, 놀이 종류, 사용자가 입력한 메모와 카드 편집값. 성장앨범 표시와 사용자가 요청한 내보내기에 사용합니다.
  • 놀이 기록: 놀이 시간, 완료·중도 종료 여부, 반복 선택 등. 다음 놀이 추천과 주간 기록 표시에 사용합니다.
  • 앱 내 사용성 기록: 화면 진입이나 버튼 선택 같은 이벤트를 개인 식별값 없이 기기 내부에만 저장할 수 있습니다. 제3자 분석 서비스나 광고 목적으로 전송하지 않습니다.
  • 구매 상태: Apple이 처리한 App Store 구매의 활성·복원 결과. Pro 기능 제공에 사용하며 카드 번호나 결제 수단 정보는 Dography가 처리하지 않습니다.

3. 카메라와 사진의 자동 저장 방식

카메라 권한을 허용하고 놀이를 시작하면 앱은 놀이 중 저해상도 후보 화면을 일시적으로 만듭니다. 기기 내 품질 검사에서 강아지가 잘 보이고 선명한 후보 한 장이 선택되면 앱 내부 성장앨범에 자동 저장됩니다. 기준을 충족하는 사진이 없으면 사진 대신 놀이 시간만 남습니다.

  • 선택되지 않은 임시 후보는 처리 후 삭제합니다.
  • 앱이 예기치 않게 종료되면 오래된 임시 후보는 다음 실행 때 정리합니다.
  • iPhone의 사진 앱으로 내보내거나 다른 앱에 공유하는 동작은 사용자가 직접 선택할 때만 실행됩니다.

4. 권한 사용

  • 카메라: 놀이 사진 후보 생성에 사용합니다.
  • 마이크: 사용자가 소리 반응 놀이에서 직접 짧은 소리를 녹음할 때만 사용합니다. 녹음은 해당 세션 동안 기기 안에서 사용되고 종료·취소 시 삭제됩니다.
  • 사진 보관함: 프로필 사진을 선택하거나, 사용자가 성장앨범 사진·카드를 사진 앱에 내보낼 때 사용합니다.

권한은 iOS 설정에서 언제든 변경할 수 있습니다. 필요한 권한을 거부하면 해당 촬영·녹음·내보내기 기능만 제한됩니다.

5. 외부 전송과 제3자 처리

Dography는 광고 SDK나 제3자 사용 분석 SDK를 포함하지 않으며, 프로필·사진·놀이 기록을 사업자 서버로 전송하지 않습니다. 사용자가 iOS 공유 화면에서 대상 앱이나 서비스를 선택하면 해당 사업자의 정책에 따라 정보가 전달될 수 있습니다.

인앱 구매와 구매 복원은 Apple이 처리합니다. Apple의 정보 처리 방식은 Apple 개인정보 처리방침에서 확인할 수 있습니다.

6. 보관, 내보내기 및 삭제

  • 프로필, 성장앨범과 놀이 기록은 사용자가 앱 안에서 삭제하거나 앱을 제거할 때까지 기기 내부에 보관됩니다.
  • 앱에서 개별 사진과 프로필을 삭제할 수 있습니다. 앱을 삭제하면 앱 내부 데이터도 함께 제거됩니다.
  • 성장앨범 전체 파일은 사용자가 ZIP 내보내기를 직접 실행해야 합니다. 현재 버전은 자동 iCloud 동기화나 ZIP 복원 기능을 제공하지 않습니다.
  • 내보낸 ZIP 또는 공유한 파일의 보관·삭제는 사용자가 선택한 저장 위치와 서비스의 정책을 따릅니다.
앱 삭제나 기기 교체 전에는 필요한 성장앨범을 ZIP으로 내보내고, 중요한 사진은 사진 앱에도 별도로 보관해 주세요.

7. 이용자의 선택과 문의

사용자는 앱 안에서 저장된 사진과 프로필을 확인·수정·삭제할 수 있고, iOS 설정에서 카메라·마이크·사진 권한을 철회할 수 있습니다. 삭제나 개인정보 처리에 관한 문의는 imaezings@gmail.com으로 보내 주세요.

8. 아동의 개인정보

Dography는 사용자 계정을 만들거나 사업자 서버로 개인정보를 전송하지 않습니다. 보호자는 아동이 기기 권한, 사진 공유 또는 구매 기능을 사용할 때 함께 확인해 주세요.

9. 방침 변경

앱 기능이나 정보 처리 방식이 변경되면 이 문서의 개정일과 내용을 갱신합니다. 중요한 변경은 앱 또는 App Store 설명을 통해 안내합니다.
