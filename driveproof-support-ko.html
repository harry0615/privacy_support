DUNDUN · SUPPORT

무엇을 도와드릴까요?

처음 기록을 시작할 때부터 백업과 구매 복원까지, 필요한 도움을 찾아보세요.

차량번호와 현재 계기판 거리로 시작하세요.

회원가입 없이 사용할 수 있어요. 운전자 이름은 세무 자료를 만들 때 입력하면 됩니다.

처음 사용자동 기록구매·체험백업·복원문의
처음 사용

기록하고, 확인하고, 보내세요

  1. 차량 등록: 차량번호와 계기판의 ODO 숫자를 입력하세요. 차종은 선택 사항이에요.
  2. 운행 기록: 자동 기록을 켜거나 홈에서 ‘운행 시작’과 ‘운행 종료’를 누르세요.
  3. 기록 확인: 운행을 업무·출퇴근·개인으로 구분하고, 계기판 거리와 비교하세요.
  4. 자료 공유: ‘세무 자료’에서 기간을 골라 엑셀·PDF를 만드세요.

지난 운행은 ‘운행 → 추가 → 직접 한 건 입력’에서 넣을 수 있어요. 차량을 새로 바꾸면 이전 차량의 기록은 남겨 두고 현재 차량을 관리할 수 있어요.

자동 기록이 잘 안 되나요?

  1. ‘더보기 → 설정 · 차량 · 백업’에서 자동 기록이 켜져 있는지 확인하세요.
  2. 앱의 ‘위치 설정하기’ 안내를 따라 iPhone 위치 권한을 확인하세요. 백그라운드 기록에는 항상 허용이 필요해요.
  3. ‘정확한 위치’와 동작 접근 권한을 확인하세요.
  4. 앱을 다시 열어 현재 상태와 ‘자동 기록 점검하기’ 안내를 확인하세요.

실내·지하 주차장이나 위치 수신이 약한 곳에서는 감지와 거리에 차이가 있을 수 있어요. 빠진 운행은 직접 추가하고, 실제 계기판 거리와 비교해 주세요.

수동으로 지난 운행을 입력할 때는 위치 권한이 필요하지 않아요.

주유 문자는 어떻게 연결하나요?

문자 자동 기록은 Pro 기능이에요. 앱이 문자함을 직접 읽는 방식이 아니라, 사용자가 iPhone 단축어에서 전달한 문자를 기록해요.

  1. 앱의 주유 문자 자동 연결 안내를 여세요.
  2. iPhone ‘단축어’ 앱에서 메시지를 받았을 때 실행하는 개인용 자동화를 만드세요.
  3. 든든 운행일지의 주유 문자 기록 동작을 추가하고, 받은 문자 내용을 ‘문자 내용’에 연결하세요.
  4. 결제 문자가 전달되면 앱에서 인식한 날짜·금액·사용처를 확인하세요.

빠진 내역은 주유 내역 가져오기 → 문자 붙여넣기에서 직접 넣을 수 있어요. 문자 형식에 따라 인식하지 못하는 항목은 직접 확인해 주세요.

무료 기능과 든든 Pro

무료
운행 기록, 운행기록부 출력, 백업
Pro
주유비·통행료 문자 기록, 엑셀과 증빙 사진을 ZIP으로 묶어 보내기
14일 후에는 문자 자동 기록과 증빙 사진 묶음 보내기에 영구 이용권이 필요해요

체험이 끝나도 자동으로 결제되지 않아요. 기존 기록과 무료 기능은 그대로 이용할 수 있어요. 영구 이용권은 한 번만 결제하며 자동 갱신되지 않아요.

가격은 앱의 구매 화면에 표시돼요.

더보기 → 설정 · 차량 · 백업 → 든든 Pro → Pro 살펴보기

체험 전에는 ‘14일 무료 체험 · Pro 살펴보기’, 체험 중에는 ‘영구 이용권 구매’로 표시될 수 있어요.

구매했는데 Pro 기능이 잠겨 있어요.

구매에 사용한 Apple 계정으로 App Store에 로그인되어 있는지 확인한 뒤, 같은 ‘든든 Pro’ 메뉴에서 구매 복원을 누르세요. 인터넷 연결이 필요할 수 있어요.

무료 체험을 복원해도 최초 시작일부터 계산한 체험 기간이 새로 시작되지는 않아요.

가격이 나오지 않거나 구매가 안 돼요.

인터넷 연결과 App Store 로그인 상태를 확인하고, 구매 화면에서 가격 다시 불러오기를 누르세요. 계속 문제가 생기면 표시된 오류 문구와 앱 버전을 알려 주세요.

체험을 취소하거나 환불받고 싶어요.

무료 체험은 자동으로 유료 전환되지 않으므로 자동 결제를 막기 위한 취소가 필요하지 않아요. 영구 이용권 환불은 Apple 문제 신고 페이지에서 요청할 수 있어요. 환불 여부는 Apple의 처리 결과에 따라 결정됩니다.

영수증과 세무 자료

사진 속 숫자가 다르게 인식돼요.

밝은 곳에서 숫자가 선명하게 보이도록 촬영하세요. 인식한 금액·날짜·거리는 저장 전에 확인하고, 필요하면 직접 고쳐 주세요.

엑셀·PDF는 어디에서 만드나요?

세무 자료에서 기간과 차량을 고르세요. 이름이 없는 기록이 있으면 운전자 이름을 입력한 뒤 공유할 수 있어요. PDF는 ‘파일 구성 → 선택 차량 PDF 보기·공유’에서 만들 수 있어요.

계기판·영수증 사진을 함께 보내려면 ‘파일 구성’의 사진 옵션을 켜세요. 이 기능에는 Pro 이용권이 필요해요.

자료에 ‘검토용’이라고 표시돼요.

‘세무 자료’의 ‘살펴볼 항목’을 눌러 거리·분류 등 확인할 내용을 보완하세요. 세무 처리에 사용할 내용은 세무사와 최종 확인해 주세요.

휴대폰을 바꾸기 전에 백업하세요

더보기 → 설정 · 차량 · 백업 → 백업·복원
  • 자동 백업: ‘자동 백업 폴더 선택’에서 iCloud Drive 등 저장할 폴더를 골라 주세요.
  • 직접 저장: ‘백업 만들기’로 파일을 저장하거나 공유하세요.
  • 새 휴대폰: 처음 화면의 ‘백업 불러오기’ 또는 설정의 ‘백업 파일 불러오기’에서 파일을 선택하세요.

백업이 저장됐는지 확인한 뒤 앱을 삭제하거나 기기를 바꿔 주세요. 백업 파일에는 이동 경로와 사진이 포함될 수 있으니 나만 접근할 수 있는 곳에 보관하세요.

기록을 완전히 지우고 싶어요.

개별 기록을 지워도 수정·삭제 이력이나 이전 백업이 남을 수 있어요. 기기의 앱 데이터 전체를 없애려면 iPhone의 앱 삭제를 사용하세요. ‘앱 정리하기’는 데이터를 남겨 둬요.

파일 앱·사진 앱·iCloud Drive의 파일, 외부에 보낸 자료와 기기 백업은 별도로 삭제해야 해요. 자동 백업 연결 해제만으로 기존 백업 파일이 지워지지는 않아요.

도움이 더 필요하신가요?

문제가 발생한 화면과 아래 정보를 알려 주시면 확인에 도움이 돼요.

  • 앱 버전, iPhone 모델과 iOS 버전
  • 어떤 동작에서 문제가 생겼는지
  • 오류 문구 또는 필요한 부분만 가린 화면 캡처

차량번호·이동 경로·카드 정보 등 문의에 필요하지 않은 내용은 가려 주세요. 비밀번호나 전체 백업 파일을 먼저 보내지 않아도 돼요.
