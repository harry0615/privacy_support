1. 처리하는 정보와 목적

사용자가 입력·선택·공유한 자료, 연결한 서비스에서 가져온 정보와 기능 수행에 필요한 정보를 다음 목적에 사용합니다. 직접 텍스트나 캡처를 저장하는 데에는 Threads 연결이 필요하지 않습니다.

구분정보목적과 처리 위치
보관함원문, 링크, 선택한 캡처, 인식된 글자, 요약, 메모, 태그, 컬렉션, 자료 식별자와 생성·수정 시각보관·검색·정리·요약·백업을 위해 기기에 저장합니다.
가져온 게시물본문, 작성자 사용자 이름, 게시물 식별자, 원문 링크, 게시 시각 등 API에서 제공한 정보선택한 Threads 자료를 가져와 원문과 출처를 표시합니다. 요청은 Meta와 연결 서버를 거치며, 보관한 자료는 기기에 저장합니다.
연결·인증Threads 계정 식별 정보, 승인된 권한과 연결 상태, OAuth 인증 정보, 세션 및 접근 토큰Threads 연결과 원문 가져오기를 위해 Meta 및 연결 서버가 처리합니다. 기기에서 사용하는 인증 정보는 iOS Keychain에 저장합니다.
공유 대기 자료공유 화면에서 넘긴 링크·텍스트·이미지와 처리 상태공유 확장에서 본 앱으로 전달하기 위해 기기의 공동 저장 공간에 임시 보관합니다.
설정·진단요약 관련 설정, 로컬 모델 정보, 요청 성공·실패 상태, 오류 메시지, 처리 수, 요청 추적 식별자, 관련 게시물·사용자 식별 정보기능 설정과 오류 안내에 사용합니다. 기기 내 진단과 별도로 네트워크 요청 과정에서 서버 로그가 생성될 수 있습니다.
고객지원발신 이메일 주소와 사용자가 문의에 포함한 내용·첨부 파일운영자와 이메일 서비스가 문의 응대 및 개인정보 요청 처리에 사용합니다.

2. Threads 연결과 외부로 전달되는 정보

Threads 연결을 선택하면 Meta의 인증 화면에서 로그인과 권한 승인을 진행합니다. ThreadShelf의 보관함에 Threads 비밀번호를 저장하지 않습니다. 연결 서버는 세션과 인증 정보를 처리하고, 사용자가 요청한 공개 게시물을 조회하기 위해 사용자 이름, 게시물·링크 식별 정보, 조회 조건 등을 Meta에 전달합니다. 응답에는 게시물 본문과 작성자 정보가 포함될 수 있습니다.

외부 원문을 가져오는 과정에서 네트워크 제공자와 서버는 IP 주소, 요청 시각 등 통신에 필요한 접속 정보를 처리할 수 있습니다. 연결 서버가 저장하는 세부 항목과 로그의 범위·보유 기간은 아래 운영 정보에 따라 공개합니다.

저장된 보관함 전체, 개인 메모 또는 캡처를 요약 목적으로 외부 AI 서비스에 자동 전송하지 않습니다. 다만 원문 가져오기, 사용자가 실행하는 공유·백업, 문의 이메일 등 선택한 동작에는 해당 자료의 전송이 수반됩니다.

연결을 해제하면 보관한 글은 유지됩니다. Meta 계정의 정보 처리에는 Meta의 개인정보처리방침이 별도로 적용됩니다.

3. 기기 내 처리와 선택한 자료에 대한 접근

캡처와 문자 인식

사진 선택 화면에서 사용자가 선택한 이미지 또는 공유한 이미지를 가져옵니다. 앱이 사진 보관함 전체를 임의로 검색하지 않습니다. 이미지 속 글자는 기기에서 인식하며, 인식 결과를 원문으로 보관하거나 요약에 사용할 수 있습니다.

요약

지원되는 환경에서는 Apple의 기기 내 언어 모델을 사용합니다. 사용할 수 없을 때에는 핵심 문장을 추출하는 방식으로 처리합니다. 별도 로컬 모델 다운로드 기능이 제공되는 구성에서는 사용자가 선택한 모델 제공자로부터 파일을 내려받으며, 제공자는 다운로드 요청의 접속 정보를 처리할 수 있습니다. 모델을 이용한 요약은 기기에서 수행합니다.

파일과 클립보드

백업 가져오기에서는 사용자가 선택한 파일을 읽습니다. 복사·붙여넣기와 공유 기능은 사용자가 실행한 동작에 필요한 텍스트를 처리합니다. 복사한 내용은 시스템 클립보드에 남을 수 있으며 운영체제 설정의 영향을 받습니다.

4. 텍스트 내보내기, 공유와 백업

‘텍스트 내보내기’는 원문·요약·메모·태그·컬렉션과 관련 정보를 JSON 형식의 파일로 만듭니다. 캡처 이미지 파일은 포함하지 않습니다. 공유 화면에서 목적지를 직접 선택하며, 이후 사본의 보관과 처리는 해당 서비스의 방침 및 사용자의 설정을 따릅니다. 텍스트 백업 자체에는 앱이 별도 암호를 설정하지 않습니다.

현재 앱은 iCloud 보관함 전송이나 기기 간 자동 동기화를 제공하지 않습니다. iCloud Drive 등에 파일을 직접 저장하거나 운영체제의 기기 백업에 앱 데이터가 포함되는 것은 별도입니다. 백업에는 보관한 자료가 포함될 수 있으므로 저장 위치와 접근 권한을 확인해 주세요.

5. 보유 기간, 삭제와 파기

기기 내 자료

보관함 자료는 사용자가 삭제할 때까지 기기에 저장합니다. 공유 대기 자료는 본 앱으로 전달·처리되거나 사용자가 데이터를 삭제할 때 정리합니다. ‘내 데이터 삭제’는 로컬 원문·요약·메모·캡처, 공유 대기 자료와 연결 정보를 삭제합니다. 개별 글 삭제 시 해당 원문을 포함한 저장된 묶음 요약도 함께 삭제될 수 있습니다.

삭제한 내용이 오래된 백업에서 다시 나타나는 것을 막기 위해 원문·메모가 없는 자료 식별자, 수정 정보와 삭제 시각 등의 삭제 표식이 기기에 남을 수 있습니다. 앱 설정과 다운로드한 모델은 별도로 남으며, 제공되는 ‘모델 삭제’ 기능으로 모델 파일을 제거할 수 있습니다.

연결 서버와 고객지원

‘내 데이터 삭제’는 연결 서버의 인증 데이터 삭제도 요청합니다. 서버 삭제를 확인하지 못하면 앱에서 재시도를 안내합니다. 네트워크 연결을 확인하고 ‘데이터 삭제 다시 시도’를 선택하거나 아래 연락처로 문의해 주세요.

별도로 관리해야 하는 사본

앱의 삭제 기능은 사진 앱의 원본, Meta의 원문·계정, 내보낸 백업, 다른 기기의 자료, 다른 사람에게 공유한 사본이나 이전 버전으로 클라우드에 보관한 자료까지 삭제하지 않습니다. 해당 서비스·저장 위치에서 따로 삭제해야 합니다. 기기의 앱을 제거하는 것만으로 연결 서버에 삭제 요청이 전달되는 것은 아닙니다.

전자 파일은 앱이 관리하는 저장소에서 삭제합니다. 운영자가 별도로 보유하는 정보의 파기 시점·방법 및 법령상 보존이 필요한 항목이 있다면 그 근거와 기간은 위 운영 정보에 명시합니다.

8. 이용자의 선택과 권리 행사

기기 내 자료는 앱에서 열람·수정·내보내기·삭제할 수 있습니다. Threads 연결은 선택 사항이며 설정에서 해제할 수 있습니다. 연결하지 않거나 해제하면 자동 원문 가져오기가 제한되지만, 이미 저장한 자료와 직접 입력한 자료는 계속 관리할 수 있습니다.

운영자가 처리하는 본인 정보의 열람·정정·삭제·처리정지, 동의 철회 및 기타 개인정보 관련 요청은 {{SUPPORT_EMAIL}}로 보내 주세요. 필요한 경우 요청자 확인에 필요한 최소한의 정보를 안내합니다. 비밀번호나 인증 토큰을 요구하지 않습니다. 관계 법령에 따른 제한이 있으면 해당 사유와 처리 결과를 안내합니다.

9. 정보 보호

Threads 연결과 원문 요청에는 HTTPS를 사용하고, 기기의 인증 정보는 iOS Keychain에 보관합니다. 보관함은 앱의 저장 공간에서 관리합니다. 이러한 조치가 사용자가 내보낸 파일이나 모든 외부 저장 위치에 동일하게 적용되는 것은 아닙니다.

기기에 암호를 설정하고 운영체제를 최신 상태로 유지해 주세요. 문의 시 보내는 화면·진단 정보에는 사용자 이름이나 게시물 식별 정보가 들어갈 수 있으므로 필요한 부분만 포함해 주세요. 전체 보관함, 사적인 메모 또는 인증 정보를 보내지 않아도 문의할 수 있습니다.
