1. 글과 캡처를 어떻게 저장하나요?

Threads나 브라우저의 공유 화면에서 ThreadShelf를 선택하거나, 앱의 ‘추가’에서 링크를 붙여 넣으세요. 직접 본문을 입력할 수 있고 ‘캡처 추가’로 선택한 이미지의 글자를 읽어 들일 수도 있습니다. 내용을 확인한 뒤 저장하거나 ‘저장하고 요약’을 선택하세요.

공유 목록에 ThreadShelf가 보이지 않으면 공유 화면의 ‘더 보기’에서 확인하세요. 공유한 내용이 즉시 표시되지 않으면 ThreadShelf를 열어 보관함을 확인해 주세요.

정리한 자료는 어떻게 다시 찾나요?

컬렉션으로 주제를 나누고 태그와 메모를 추가할 수 있습니다. 검색으로 원문·요약·태그·메모에서 필요한 내용을 찾으세요. 요약은 복사하거나 시스템 공유 화면을 통해 보낼 수 있습니다.

2. Threads 연결이 꼭 필요한가요?

직접 입력한 텍스트와 선택한 캡처는 Threads 연결 없이 보관할 수 있습니다. Threads 원문을 자동으로 가져오려면 ‘설정’의 ‘Threads 연결’에서 계정을 연결하세요. 로그인과 권한 승인은 Meta의 인증 화면에서 진행합니다.

링크를 넣었는데 본문을 가져오지 못해요.

인터넷 연결, 계정 연결 상태, 게시물 공개 여부와 링크가 올바른지 확인하세요. 비공개·삭제된 게시물, API에서 제공하지 않는 게시물이나 승인 범위를 벗어나는 자료는 가져오지 못할 수 있습니다. 모든 답글이나 스레드 전체를 가져오는 기능은 아닙니다. 직접 본문을 붙여 넣거나 필요한 부분을 캡처해 추가할 수 있습니다.

연결을 해제하면 저장한 글도 없어지나요?

‘연결 해제’는 보관함의 글을 삭제하지 않습니다. 보관 데이터와 연결 정보를 함께 지우려면 ‘내 데이터 삭제’를 사용하세요. 이 동작은 Meta 계정이나 Threads에 게시한 원문을 삭제하지 않습니다.

3. 요약은 어떻게 만들어지나요?

요약은 기기에서 처리합니다. Apple의 온디바이스 AI 요약에는 iOS 26 이상과 Apple Intelligence를 사용할 수 있는 지원 기기 및 설정이 필요합니다. 지원 여부와 모델 준비 상태에 따라 이용할 수 없을 수 있으며, 이때는 원문의 핵심 문장을 추출하는 방식으로 정리합니다.

여러 글을 함께 정리하려면 최대 20개를 선택해 묶음 요약을 만드세요. 요약이 실제 원문을 제대로 반영하는지 출처와 함께 확인해 주세요. 요약에는 오류나 중요한 맥락의 누락이 있을 수 있습니다.

캡처의 글자를 잘못 읽거나 일부만 요약해요.

글자가 선명한 이미지를 선택하고, 인식된 본문을 확인·수정한 뒤 다시 요약하세요. 캡처에 보이지 않는 본문이나 답글은 요약의 근거에 포함되지 않습니다. 이미지 문자 인식은 기기에서 이루어집니다.

인터넷 없이도 사용할 수 있나요?

이미 기기에 저장한 글을 열람하고 정리할 수 있습니다. 요약은 사용할 수 있는 기기 내 모델 또는 핵심 문장 추출 기능을 사용합니다. Threads 연결·원문 가져오기, 필요한 모델 다운로드, 고객지원 웹페이지 열기에는 인터넷이 필요합니다.

4. 텍스트 백업을 만들고 가져오는 방법

  1. ‘설정’ → ‘텍스트 백업’ → ‘텍스트 내보내기’를 선택하세요.
  2. 시스템 공유 화면에서 보관할 위치를 선택하고 파일을 저장하세요.
  3. 복원할 때는 ‘백업 가져오기’를 선택해 ThreadShelf에서 내보낸 텍스트 백업 파일을 여세요.

백업은 원문·요약·메모·태그·컬렉션 등의 정보를 담는 JSON 형식의 파일입니다. 일반 메모 파일이나 다른 앱의 내보내기 파일은 같은 방식으로 가져올 수 없습니다.

캡처 이미지 파일은 백업에 포함되지 않습니다. 이미지가 필요하면 별도로 보관하세요. 내보낸 파일은 내용이 읽히는 텍스트이므로 접근 권한이 있는 사람에게 내용이 노출될 수 있습니다.

다른 기기로 옮기거나 iCloud로 동기화할 수 있나요?

현재 앱에는 iCloud 자동 동기화나 ‘iCloud 보관함으로 전송’ 기능이 없습니다. 다른 기기로 옮길 때는 텍스트 백업 파일을 전달한 뒤 가져오세요. 시스템 파일 화면에서 iCloud Drive를 저장 위치로 선택하는 것은 파일 보관이며, 앱 보관함의 자동 동기화와는 다릅니다.

백업을 가져오지 못해요.

ThreadShelf에서 내보낸 원본 파일인지, 다운로드가 끝났는지, 내용을 편집하거나 손상시키지 않았는지 확인하세요. 문제가 계속되면 오류 문구와 앱 버전을 문의해 주세요. 처음부터 보관함 전체 파일을 이메일로 첨부하지는 마세요.

5. 보관한 데이터는 어떻게 삭제하나요?

개별 글은 보관함에서 삭제할 수 있습니다. 해당 글이 포함된 저장된 묶음 요약도 함께 삭제될 수 있습니다. 전체를 삭제하려면 ‘설정’의 ‘내 데이터 삭제’를 선택하고 확인하세요. 진행 전에 보관할 텍스트는 내보내고, 열려 있는 공유 확장을 닫아 주세요.

전체 삭제는 기기의 원문·요약·메모·캡처와 공유 대기 자료, 연결 정보를 삭제하고 연결 서버의 인증 데이터 삭제도 요청합니다. ‘기기 보관 데이터는 지웠지만 서버 인증 데이터 삭제를 확인하지 못했다’는 안내가 나오면 인터넷 연결을 확인한 뒤 ‘데이터 삭제 다시 시도’를 누르거나 문의해 주세요.

앱 설정과 다운로드한 로컬 모델은 별도로 남을 수 있습니다. 모델을 내려받은 경우 ‘모델 삭제’로 제거할 수 있습니다. 삭제한 자료가 오래된 백업에서 다시 살아나지 않도록 내용이 없는 삭제 표식이 기기에 남을 수 있습니다.

사진 앱의 원본, 직접 내보낸 파일, 다른 기기의 자료, 외부에 공유한 사본, 이전 버전으로 클라우드에 남긴 자료는 함께 삭제되지 않습니다. 해당 저장 위치에서도 직접 정리해 주세요. 기기에만 저장했고 백업이 없는 자료를 고객지원에서 복구할 수는 없습니다.

6. 개인정보는 어떻게 처리하나요?

보관함, 캡처 문자 인식과 요약은 기기에서 처리합니다. Threads 원문을 가져오면 Meta와 연결 서버가 인증 및 요청 정보를 처리합니다. 파일을 내보내거나 문의 이메일을 보낼 때에도 사용자가 선택한 서비스로 정보가 전달됩니다. 자세한 내용은 개인정보처리방침에서 확인하세요.

ThreadShelf는 Meta 또는 Threads가 제공하는 공식 앱이 아닙니다.
