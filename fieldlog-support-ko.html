무엇을 도와드릴까요?

처음 설정부터 출장비 보내기, 구매 복원과 백업까지 필요한 도움을 찾아보세요.

회사 기준 → 내 차 등록 → 자동 기록, 세 가지면 시작이에요.

회원가입 없이 사용할 수 있어요. ‘오늘’ 화면의 ‘시작 준비’ 목록을 따라가면 돼요.

처음 사용자동 기록외근 확인출장비 보내기구매·체험백업·복원문의
처음 사용

기록하고, 확인하고, 보내고, 받으세요

  1. 회사 기준: 출장비를 받는 방식(km당 금액·기름값 계산·영수증 실비)과 금액, 청구처, 청구인(이름·소속·직위)을 정하세요.
  2. 내 차 등록: 차량번호와 계기판의 ODO 숫자를 입력하세요.
  3. 자동 기록: 위치 권한을 ‘항상’으로 허용하면 운행이 저절로 쌓여요.
  4. 외근 확인: 외근이 끝나면 ‘오늘’에 묶음 카드가 떠요. 맞으면 [맞아요, 저장]을 누르세요.
  5. 출장비 보내기: 회사 양식 청구서(PDF·엑셀)를 보내면 ‘제출함’이 되고, 돈이 들어오면 [받았어요]를 누르세요.

회사 기준은 ‘설정 → 청구처와 정산 기준’에서 언제든 바꿀 수 있어요. 기준을 바꿔도 이미 만든 청구서 금액은 그대로예요.

자동 기록이 잘 안 되나요?

  1. ‘설정 → 운행과 결제 내역 → 자동 운행 기록 설정’에서 자동 기록이 켜져 있는지 확인하세요.
  2. iPhone 위치 권한을 항상 허용으로, ‘정확한 위치’를 켜 주세요.
  3. ‘오늘’ 화면의 상태 줄에 ‘자동 기록을 확인해 주세요’가 보이면 [점검]을 눌러 안내를 따르세요.

실내·지하 주차장처럼 위치 수신이 약한 곳에서는 감지와 거리에 차이가 있을 수 있어요. 놓친 운행은 ‘오늘 → 지난 운행 추가’에서 출발지·도착지 주소로 넣을 수 있어요(지도 경로 거리).

기록이 늦게 시작되면 ‘지금 직접 시작’을 눌러도 돼요. 직접 입력에는 위치 권한이 필요하지 않아요.

외근 카드와 비용

외근 카드가 안 떠요.

업무 운행이 끝나야 카드가 떠요. ‘설정 → 회사·집 위치’에 회사를 저장하면 회사에서 나가 돌아오는 하루를 더 정확히 묶어요. ‘외근 아님’으로 숨긴 카드는 ‘출장비 → 출장 직접 만들기’로 다시 묶을 수 있어요.

영수증이 외근에 붙지 않아요.

결제 시각이 외근 시간(앞뒤 30분) 안이면 자동으로 붙어요. 시각이 없는 같은 날 비용은 카드에서 ‘이 출장 비용인가요?’로 물어봐요. 회사 기준이 기름값을 이동비에 포함하면 주유 영수증은 청구에서 빠져요(비용 입력 화면에서 바로 알려 드려요).

잘못 저장했어요.

저장·받음·숨김 직후 아래 알림 줄의 [되돌리기]를 5초 안에 누르세요. 그 뒤에는 ‘출장비’에서 출장을 열어 묶음 풀기를 하면 돼요. 청구서에 들어간 출장은 먼저 청구서를 취소해야 바꿀 수 있어요.

주차비 영수증을 자꾸 잊어요.

‘설정 → 지출 장소 알림’을 켜면 주차장에 들렀다 나온 뒤 ‘주차비를 내셨나요?’를 물어요. [영수증 찍기]나 [금액 입력]을 누르면 시각까지 채워져 그 외근에 바로 붙어요. 회사 기준이 영수증 실비면 주유소·충전소도 물어요. 알림은 운행마다 한 번, 하루 두 번까지이고, 회사·집 근처는 묻지 않아요.

결제 문자로 비용을 넣고 싶어요.

카드 결제 문자를 길게 눌러 복사한 뒤 ‘설정 → 운행과 결제 내역 → 결제 문자 붙여넣기’에서 넣으세요. 여러 건도 한 번에 되고, 카드 앱 결제 화면 캡처에서 읽을 수도 있어요. 앱은 문자함을 읽거나 문자를 자동으로 받아 오지 않아요. 무료예요.

출장비 보내기와 청구서 양식

  1. ‘오늘’ 또는 ‘출장비’에서 [출장비 보내기]를 누르세요.
  2. 기간과 출장을 고르고 청구서 칸(구분·기간·출장자·직위·출장지·교통편·목적)을 확인하세요.
  3. PDF·엑셀·영수증 사진 묶음 중 하나로 보내면 ‘회사에 냈나요?’를 물어요. [냈어요]를 누르면 ‘제출함’이 돼요.

‘보내기’ 화면에는 그 기간에 아직 확인하지 않은 외근과, 어떤 출장에도 묶이지 않은 업무 운행이 함께 보여요. 월말에 몰아서 정산해도 빠지지 않아요.

회사 양식에 맞추려면 ‘설정 → 청구서 양식’에서 양식 이름, 회사명, 결재란 칸 수와 이름, 영수 서명란을 바꾸고 [견본 보기]로 확인하세요. 바꾼 양식은 다음 청구서부터 적용돼요.

‘파일 보냄 · 제출 전’은 무엇인가요?

공유 창은 파일을 저장만 해도 ‘보냄’으로 끝나요. 그래서 회사에 실제로 냈는지는 따로 물어요. 나중에 냈다면 청구서의 [회사에 냈어요] 또는 ‘출장비’ 탭의 [냈어요]를 누르세요.

마감일을 알려 주세요.

‘설정 → 출장비 마감일’에서 매월 날짜(또는 말일)를 고르면, 보낼 출장비가 있을 때 마감 이틀 전 아침 9시에 알려 드려요.

무료 기능과 외근로그 Pro

무료
운행 기록, 외근 묶기, 비용 연결, 받을 돈 관리, 마감일 알림, 백업, 양식 견본 보기, 첫 청구서 1건 보내기
Pro
두 번째 청구서부터 보내기(PDF·엑셀·영수증 사진 묶음)
첫 청구서는 무료, 두 번째부터 영구 이용권이 필요해요(14일 무료 체험 있음)

체험이 끝나도 자동으로 결제되지 않아요. 기존 기록과 무료 기능은 그대로 이용할 수 있어요. 영구 이용권은 한 번만 결제하며 자동 갱신되지 않아요.

가격은 앱의 구매 화면에 표시돼요.

설정 → 외근로그 Pro → 14일 무료 체험 · Pro 살펴보기
구매했는데 청구서를 보낼 수 없어요.

구매에 사용한 Apple 계정으로 App Store에 로그인되어 있는지 확인한 뒤 ‘설정 → 외근로그 Pro → 구매 복원’을 누르세요. 인터넷 연결이 필요할 수 있어요.

무료 체험을 복원해도 최초 시작일부터 계산한 체험 기간이 새로 시작되지는 않아요.

가격이 나오지 않거나 구매가 안 돼요.

인터넷 연결과 App Store 로그인 상태를 확인하고, 구매 화면에서 가격 다시 불러오기를 누르세요. 계속 문제가 생기면 표시된 오류 문구와 앱 버전을 알려 주세요.

체험을 취소하거나 환불받고 싶어요.

무료 체험은 자동으로 유료 전환되지 않으므로 취소가 필요하지 않아요. 영구 이용권 환불은 Apple 문제 신고 페이지에서 요청할 수 있어요. 환불 여부는 Apple의 처리 결과에 따라 결정됩니다.

휴대폰을 바꾸기 전에 백업하세요

설정 → 백업과 복원 → 백업 파일 만들기
  • 저장: 공유 창에서 ‘파일에 저장 → iCloud Drive’를 권해요. ‘나의 iPhone’에 저장하면 휴대폰을 잃어버렸을 때 함께 사라져요.
  • 새 휴대폰: 처음 화면의 ‘다른 폰에서 쓰던 기록 불러오기’에서 파일을 고르세요. 불러오기는 기록이 없는 처음 상태에서만 할 수 있어요.

백업에는 운행·출장·청구서·지급 이력과 영수증 사진이 함께 들어가요. 나만 접근할 수 있는 곳에 보관하세요.

iPhone의 iCloud 백업(설정 → 내 이름 → iCloud → iCloud 백업)을 켜 두면 새 iPhone으로 옮길 때 앱 기록도 함께 옮겨져요. 청구서를 낸 뒤 마지막 백업이 30일을 넘었으면 앱이 한 번 알려 드려요.

기록을 완전히 지우고 싶어요.

기기의 앱 데이터 전체를 없애려면 iPhone의 앱 삭제를 사용하세요. ‘앱 정리하기’는 데이터를 남겨 둬요. 파일 앱·iCloud Drive에 저장한 백업, 보낸 청구서 파일은 별도로 삭제해야 해요.

도움이 더 필요하신가요?

문제가 발생한 화면과 아래 정보를 알려 주시면 확인에 도움이 돼요.

  • 앱 버전, iPhone 모델과 iOS 버전
  • 어떤 동작에서 문제가 생겼는지
  • 오류 문구 또는 필요한 부분만 가린 화면 캡처

차량번호·이동 경로·방문처·카드 정보 등 문의에 필요하지 않은 내용은 가려 주세요. 비밀번호나 전체 백업 파일을 먼저 보내지 않아도 돼요.
