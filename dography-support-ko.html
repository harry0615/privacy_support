자주 묻는 질문

Dography에서 무엇을 만들 수 있나요?

포토 카드는 템플릿·스타일·배경·문구·출력 비율을 조합한 정지 이미지입니다. 플래시 카드는 카드 등장·빛 스윕·반짝임 효과를 더한 6초 세로 MP4 영상입니다. 사진 한 장으로 시작한 뒤 원하는 결과를 선택하세요.

사진은 언제 카드 사진함에 추가되나요?

사용자가 촬영 버튼을 누르거나 사진 보관함에서 사진을 직접 선택한 경우에만 추가됩니다. Dography는 사진을 자동 촬영·저장·업로드·공유하지 않습니다.

선택한 사진이 추가되지 않아요.

Dography는 기기 안에서 강아지 포함 여부와 선명도 같은 기술적 품질을 확인할 수 있습니다. 밝고 흔들림이 적은 사진을 선택하고, 강아지가 화면 안에 충분히 보이는지 확인해 주세요. 추가되지 않은 사진과 처리 중 생성된 임시 파일은 처리 후 삭제됩니다.

카메라 또는 사진 선택이 작동하지 않아요.

iPhone 설정의 Dography 항목에서 카메라와 사진 접근 권한을 확인해 주세요. 권한을 거부하거나 철회하면 해당 촬영·사진 선택·저장 기능이 제한될 수 있습니다.

완성한 카드는 어떻게 저장하거나 공유하나요?

정지 이미지는 포토 카드 저장 또는 포토 카드 공유를 선택하세요. 플래시 카드는 6초 영상을 먼저 만든 뒤 사진 앱에 저장 또는 공유를 선택합니다. 사용자가 이 작업을 직접 선택한 경우에만 콘텐츠가 앱 밖으로 나갑니다. Dography 운영자 서버로 사진, 선택 입력한 프로필, 카드 프로젝트 또는 완성 카드를 전송하지 않습니다.

앱 삭제나 기기 교체 전에 무엇을 해야 하나요?

보관할 포토 카드와 플래시 카드 영상을 사진 앱 또는 파일 앱에 저장해 주세요. 카드 사진함과 최근 카드 프로젝트는 현재 기기에 저장되며 iCloud를 통해 자동 동기화되거나 복원되지 않습니다.

Pro 구매를 복원하고 싶어요.

결제 화면의 구매 복원을 선택하고 구매에 사용한 Apple 계정이 같은지 확인해 주세요. 결제는 Apple이 처리하므로 카드 번호를 이메일로 보내면 안 됩니다.

Dography 데이터를 삭제하고 싶어요.

카드 사진함이나 프로필 설정에서 제공하는 삭제 기능으로 개별 항목을 제거할 수 있습니다. Dography 앱을 삭제하면 카드 사진함, 최근 카드 프로젝트, 선택 입력한 프로필과 캐시 영상 파일도 앱 전용 저장 공간에서 제거됩니다. 사진 앱·파일 앱·다른 앱으로 내보낸 사본은 해당 위치에서 별도로 삭제해야 합니다.

안전하게 촬영하기

강아지를 억지로 움직이거나 특정 자세를 취하게 하지 마세요. 촬영 중 강아지가 불편해하거나 피로해하면 바로 멈춰 주세요. ‘플래시 카드’는 완성 영상의 효과를 뜻하며 Dography는 카메라 플래시나 마이크 권한을 요구하지 않습니다.
